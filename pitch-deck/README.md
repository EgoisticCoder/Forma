# FORMA investor brief

Open `index.html` in a browser and present with the arrow keys. Press **P** or use Print → Save as PDF to export a 12-slide deck. The presentation follows YC’s public advice to explain the company plainly, make a small number of points memorable, keep slides legible, and separate verified evidence from assumptions. It deliberately does not invent a founder biography, market size, customer traction, pricing, funding ask, or GPU economics.

Current local evidence used on slide 8: 1,687 labeled capture records, 1,603 training rows and 84 validation rows, plus the 20-sample internal metrics in `Kaggle_Trained/eval_metrics.json`. The deck labels the evaluation as internal, small, and not independently reviewed. These dataset screenshots are not being redistributed by this deck.
